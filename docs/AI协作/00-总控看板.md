## 4. 协作铁律

- 每个窗口开始前必须读取：`AGENTS.md`、本文件、对应 `tasks/Txxx-*.md`。
- 每个窗口只改自己的文件范围；确需跨范围，先回总控窗口确认。
- 每个窗口结束前必须更新任务文件的“当前状态 / 已完成 / 下一步 / 风险”。
- `git add` 必须明确到文件名，不使用 `git add .`。
- 严禁 push、远程建分支、远程 tag，除非项目负责人明确要求。
- 涉及生产服务器、密码、密钥、数据库写入，必须先确认风险和回滚点。
