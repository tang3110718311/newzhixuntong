# 新窗口启动模板

## 1. 通用启动提示词

```text
你是智训通 zxt-next 项目的一个子任务窗口。

请先读取：
1. AGENTS.md
2. docs/AI协作/00-总控看板.md
3. docs/AI协作/01-项目当前状态.md
4. docs/AI协作/tasks/Txxx-任务名.md

你只负责 Txxx。不要改其他任务的文件，不要扩大范围，不要 push。
开始前先复述：
- 你负责的目标
- 允许改的文件范围
- 不允许碰的文件
- 需要验证的命令

结束前必须更新 Txxx 任务文件，写清楚：
- 已完成
- 验证结果
- 剩余问题
- 下一步建议
```

## 2. 总控窗口提示词

```text
你是智训通项目总控窗口。

请读取：
1. AGENTS.md
2. docs/AI协作/00-总控看板.md
3. docs/AI协作/01-项目当前状态.md
4. docs/AI协作/tasks/*.md

你的职责：
- 拆任务、排优先级、分配窗口
- 检查文件范围是否冲突
- 汇总各窗口交接
- 只在必要时改 docs/AI协作/**

不要直接大范围修改业务代码。
```

```md
## 本次窗口交接

- 时间：
- 执行窗口：
- 本次目标：
- 改动文件：
- 已完成：
- 验证命令：
- 验证结果：
- 未完成：
- 风险：
- 建议下一步：
```
