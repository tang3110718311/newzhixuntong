## 免密部署方式

### 单独重启移动端

```bash
sudo -n /usr/local/sbin/zxt-next-mobile-restart
```

### 部署新版本包

1. 先把打包好的源码上传到：`/data/zxt-next/incoming/`
2. 包名格式：`zxt-next-<git短sha>-<yyyymmdd-hhmmss>.tar.gz`
3. 免密部署命令：

```bash
sudo -n /usr/local/sbin/zxt-next-deploy-package zxt-next-<sha>-<yyyymmdd-hhmmss>.tar.gz
```

### 脚本行为

- 自动解包到新的 release 目录。
- 自动更新 `/data/zxt-next/deploy/env.test` 的 `ZXT_RELEASE_DIR`。
- 自动重建 `zxt-api`、`zxt-admin`、`zxt-mobile`。
- 自动保留生产机其他服务不动。

## 经验记录

- 生产构建第一次失败在 `edge-tts` pip 下载，原因是 `files.pythonhosted.org` 下载超时。
- 生产 `/data/zxt-next/deploy/Dockerfile` 已热修 pip 参数：国内 PyPI 镜像、长超时、重试、`--break-system-packages`。
- 后续若同步本地 Dockerfile，要保留这类构建稳定性处理。
