# T004 - 移动端考试流程可用性

## 目标

保证移动端考试从列表、进入考试、答题、提交、评分、查看报告形成可用闭环。

## 文件范围

- 移动端：`apps/mobile/src/components/ExamsPage.tsx`、`ScenarioExam.tsx`、`ExamReport.tsx`
- 后端：`apps/api/app/api/exams/**`、`exam-attempts/**`、`exam-questions/**`
- 数据库：`packages/database/src/repository.ts`
- 共享类型：`packages/shared/src/**`

## 待拆解

- 考试列表是否只展示可参加考试。
- 草稿/未发布考试是否不能开始。
- 单选、多选、判断题是否都能提交。
- 提交后分数、通过状态、解析、报告是否正确。
- 刷新页面后考试记录是否仍可查看。
- 管理端创建/发布考试后移动端是否实时可见。

## 验证建议

```bash
npm.cmd run smoke:p1:exam
npm.cmd run build
```

浏览器验证：

- 管理端创建/发布考试。
- 移动端登录学员账号。
- 完整做一场考试并查看报告。

## 风险

- 不要把未发布考试暴露给学员。
- 不要把答案提前泄露到学员端，除非是提交后的解析。
