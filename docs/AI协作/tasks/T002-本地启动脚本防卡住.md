# T002 - 本地启动脚本防卡住

## 目标

修复 `npm.cmd run start:local -- --restart` 在 Windows / Codex 环境下卡住或误失败的问题。

## 文件范围

- 允许改：`scripts/start-local.mjs`
- 必要时只读：`scripts/stop-local.mjs`、`.logs/**`
- 不改业务代码。

## 当前状态

doing

## 已知问题

- Windows 下长生命周期 `next start` 进程如果继承父进程 stdout/stderr，Codex/PowerShell 可能一直等待。
- PowerShell `Start-Process` 对长生命周期进程配合重定向时可能出现“已输出 PID 但父命令 ETIMEDOUT”的假超时。
- 根目录曾出现过空文件 `process.exit(0)`，已清理。

## 已完成

- `scripts/start-local.mjs` 已改为 Windows 分支使用 `Start-Process` 启动独立进程。
- 已处理 PowerShell 假超时：拿到 PID 后继续等待 HTTP 健康检查。
- 已验证：
  - `node --check scripts/start-local.mjs`
  - `npm.cmd run start:local -- --restart`
  - `npm.cmd run start:local`
  - API/Admin/Mobile 三端 HTTP 200

## 下一步

- 若准备提交，只提交 `scripts/start-local.mjs`。
- 提交前再次执行：

```bash
npm.cmd run start:local -- --restart
npm.cmd run start:local
```
