## 4. 技术架构

这是一个 Next.js monorepo：

```text
apps/admin              管理端 H5 / 前端页面
apps/api                独立 API 服务
packages/database       SQLite/Prisma/仓储层
packages/shared         前后端共享类型和 schema
packages/ai-provider    LLM/STT/TTS 等 AI 能力适配层
docs                    设计、计划、交接文档
deploy                  Docker 部署相关
```

关键原则：

- `apps/admin` 只能调用 HTTP API，不能直接访问数据库、文件系统、模型 Key。
- `apps/api` 是唯一数据访问层，负责认证、租户隔离、AI 调用、文件上传、审计。
- 数据库当前用 SQLite 本地验证，后续必须能迁移 MySQL。
- LLM、STT、TTS、OCR、评分都按接口能力预留，不要把供应商写死在前端。
- SaaS 相关要关注租户隔离、套餐额度、用量统计、配置加密、审计字段。

要求：

- 学员点击说话时，应停止当前 AI 语音。
- 麦克风报错时先查 HTTPS/localhost、浏览器权限、CSP、录音 API。
- TTS 声音要尽量自然，edge-tts 只是 fallback，不要把前端绑定死某个 voice name。
- 同一场景内声音要固定；不同场景可以随机男/女声。
- 客服训练中的 angry/urgent 情绪要明显，让学员感到真实压力。
- 对练结束后要能生成训练记录和评分复盘。
