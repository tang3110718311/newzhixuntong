## 2026-08-12（feat-mobile 分支）

### A. 工具与文档：UTF-8 中文提交 + 变更记录（本次新增）
- **新增 `scripts/setup-git-utf8.mjs`**：一键配置 Git 全局编码为 UTF-8（团队首次拉代码后跑一次）
- **新增 `scripts/git-commit-utf8.mjs`**：项目内中文提交工具，避免 PowerShell 编码坑
- **协作文档增加"中文提交配置"小节**：让团队（含产品经理）知道怎么避免乱码

### 1. 语音服务：接入旧版智训通语音（TTS/STT）
- **做什么**：本地开发时语音走旧版智训通自有服务，效果更好
- **TTS（文字转语音）**：`http://171.109.109.90:10030`（已验证可用，返回 wav）
- **STT（语音转文字）**：`wss://zxt.xingyiwulian.cn:8765`
- **配置方式**：复制 `apps/api/.env.example` → `apps/api/.env` 即可（模板已提交）
- **回退机制**：TTS 失败自动回退 edge-tts（微软免费语音），保证功能不中断

### 2. 管理端：移除"对练中心"导航
- **做什么**：登录后左侧菜单不再显示"对练中心"
- **原因**：与原型导航一致（原型侧边栏无此项）
- **不影响**：对练功能仍可从"任务详情 → 开始对练"、"场景管理 → 创建任务"进入

### 3. 团队协作：企业微信通知
- **做什么**：推送到 main/feat-mobile 分支时，自动发企业微信通知
- **配置**：GitHub Actions 的 Secrets 需配置企业微信机器人 webhook
